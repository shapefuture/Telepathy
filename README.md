# Telepathy

Telepathy is a planned, privacy-first **Community Intelligence OS** for Telegram communities: source-cited knowledge retrieval, approved meeting/document search, verified opt-in expert discovery, and consent-based introductions.

**Status:** Planning and project bootstrap. This repository does not yet contain a deployed bot or production service.

Architecture and task plan will be introduced through a reviewed GitHub pull request. GitHub Issues will be the authoritative task tracker; no issue is complete without observable acceptance evidence.

**Important:** Do not upload Telegram chat transcripts, credentials, private member details, or identifiable data to this public repository. NVIDIA NIM trial and Decision 3.0 free-classifier integrations are prototype-only until privacy and terms-of-service gates are satisfied.
